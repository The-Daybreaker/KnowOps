# Obsidian 知识库 · 用户手册

> 本手册由 obsidian-kb skill 在首次初始化时生成，面向知识库的使用者。
> 手册可以随手修改或删除，不影响 skill 运行（重复初始化不会覆盖你的手册）。

## 这个知识库怎么用？

你的知识库由 **Obsidian + AI agent** 共同维护：

- **你**：在 Obsidian 里自由写作、浏览、建立链接；
- **AI agent**：在对话里帮你记录、整理、搜索、剪藏、写日记、做视图、导出网页版。

对 agent 说出需求即可，例如：

| 你说 | agent 做 |
|---|---|
| "帮我记录一个问题：……" | 建一篇结构化笔记（含属性、来源），写前查重，写后同步网页版 |
| "剪藏这篇文章：<URL>" | 提取正文存为带来源属性的剪藏笔记 |
| "记录今天的日记：……" | 追加到今天的日记（按月自动分目录） |
| "我有哪些待办任务？" | 汇总全库 `- [ ]` 任务 |
| "把这篇笔记移到归档" | 先给你看方案，你确认后才移动（链接自动更新） |
| "删掉那篇测试笔记" | 你确认后删除，**进系统回收站，可恢复** |
| "做一个任务看板" | 生成 Bases 视图（.base） |
| "画一张学习路线画布" | 生成 Canvas 画布（.canvas） |

## 首次使用流程

1. 告诉 agent 你要管理哪个知识库（vault 的实际路径与名称——就是你创建时的名字，
   agent 不会瞎猜）；
2. agent 与你确认后，在**大知识库文件夹**（vault 的上级目录）生成：
   - `obsidian-kb.config.json` —— 配置文件（vault 位置、导出目录、偏好）；
   - `用户手册.md` —— 就是本文件；
   - `HTML-Export/` —— 网页版镜像目录（名称位置可改）；
3. 你的 vault 内部**始终干净**：只有你自己的笔记和 Obsidian 自身的文件。

## 目录结构（默认，可改）

```
大知识库文件夹/
├── obsidian-kb.config.json   # 配置（agent 用）
├── 用户手册.md               # 本文件
├── HTML-Export/              # 网页版镜像（手机浏览器直接打开 index.html）
└── <你的 Vault>/
    ├── 00-Inbox/             # 收件箱：随手记
    ├── 10-Daily/             # 日记（2026-08/2026-08-03.md 这样按月分）
    ├── 20-Projects/          # 项目
    ├── 30-Areas/             # 领域/主题
    ├── 40-Resources/         # 资源（剪藏在 Clips/）
    ├── 50-Archive/           # 归档
    ├── 99-Meta/              # 模板 / Bases 视图 / Canvas 画布
    └── Attachments/          # 附件
```

## 设计理念（为什么这样搭）

- **Obsidian 原生 + CLI**：日记、模板、Bases、Canvas 全是 Obsidian 自己的能力，
  agent 通过官方 CLI 调用，不重复造轮子；
- **Vault 是唯一数据源**：没有第二份数据库、没有同步映射，文件即真相；
- **配置驱动**：路径、目录、习惯全在 `obsidian-kb.config.json` 里，换电脑、
  换库都能迁移；
- **安全红线**：
  - 删除只走 CLI，进系统回收站（回收站里能找回来）；
  - 修改、移动、删除已有内容前，agent 必须先给你看方案、经你同意；
  - 新建内容不需要同意，但会先查相似内容，发现雷同由你定夺；
  - 如果你的 vault 是 Git 仓库，agent 每次写完自动提交一次（只提交，绝不帮你建仓库）。

## 网页版（HTML-Export）是什么？

每次 agent 新增 / 修改 / 删除笔记后，都会自动把 vault 镜像成一套独立 HTML
放到 `HTML-Export/<库名>/` 下，目录结构与 vault 一致，首页是 `index.html`。
把手机连上同一目录（或用你喜欢的同步方式拷过去），浏览器打开即可阅读——
双链可点击、流程图可渲染，不需要安装 Obsidian。

## 常见问题（FAQ）

**Q：agent 删错了怎么办？**
A：打开系统回收站还原即可。agent 的删除永远进回收站，不做彻底删除。

**Q：我直接改 vault 里的文件，agent 知道吗？**
A：知道。vault 就是唯一数据源，agent 每次操作都是实时读取的。网页版镜像会在
agent 下次写操作后自动对齐（也可以随时让它"全量重建网页版"）。

**Q：可以管多个库吗？**
A：可以。配置里注册多个 vault 后，说"用工作库做……"或让 agent 切换默认库即可。

**Q：Obsidian 没打开时 agent 能操作吗？**
A：写入类操作需要 Obsidian 运行（CLI 会尝试自动拉起，拉不起来会提醒你打开）。
网页版导出不要求 Obsidian 打开。

**Q：配置文件坏了 / 想换电脑？**
A：配置文件是纯文本 JSON，可备份、可手改；到新环境让 agent 重新初始化即可，
不会动你 vault 里的任何内容。

**Q：日记为什么在某个年月子目录里？**
A：日记按 `年月/日期` 两层目录自动归档（如 `10-Daily/2026-08/2026-08-03.md`），
这是初始化时约定的格式，可在配置中调整。
