# 暂存条目模板（capture-template）

> 随身端生成暂存条目时对照本模板。输出为**完整可复制的 markdown 文本块**；
> agent 支持生成文件时同时生成 `YYYY-MM-DD 标题.md`。

## 完整模板

```markdown
---
type: capture
capture_kind: <灵感 | 随手记 | 待整理内容>
created: YYYY-MM-DDTHH:MM
tags: [标签1, 标签2]
---

# YYYY-MM-DD 一句话标题

（正文：用户原话整理，保留背景与上下文，可多行。信息以用户给出为准，不臆造。）

> 建议归属：<可选，如 02 知识系统/经验方法>
```

## 填写说明

字段格式见 `references/mobile-capture.md` 第 2 步；本模板只规定输出形状：
正文记完整（背景/上下文/关键信息），「建议归属」可选。

## 示例

用户口述：“刚才想到一个点子，可以用知识库的收件箱审阅机制做个每周回顾，把
一周内沉淀的知识串起来，应该能减少知识孤岛。”

```markdown
---
type: capture
capture_kind: 灵感
created: 2026-08-10T14:30
tags: [灵感, 知识管理]
---

# 2026-08-10 每周回顾：用收件箱审阅串起沉淀知识

刚才想到一个点子：用知识库的收件箱审阅机制做每周回顾，把一周内沉淀的知识
串起来，应该能减少知识孤岛、让知识点之间产生连接。

> 建议归属：02 知识系统/经验方法
```
