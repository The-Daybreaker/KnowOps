# 暂存条目模板（capture-template）

> 随身端生成暂存条目时对照本模板。输出为**完整可复制的 markdown 文本块**；
> agent 支持生成文件时同时生成 `一句话标题.md`。

## 完整模板

```markdown
---
type: capture
capture_kind: <灵感 | 随手记 | 待整理内容 | 摘录>
created: YYYY-MM-DDTHH:MM
tags: [标签1, 标签2]
---

# 一句话标题

（正文：用户原话完整记录，不改写、不压缩，怎么说的就怎么记，保留背景与
上下文，可多行。信息以用户给出为准，不臆造；补充说明只按用户要求添加。
唯一例外：语音转文字的明显错字可顺手修正，不脑补缺失信息。）
```

## 填写说明

字段格式见 `references/mobile-capture.md` 第 2 步；本模板只规定输出形状：
标题**不带日期**（日期由 `created` 承载），正文是**用户原话的完整记录**
（不改写、不压缩；补充说明只按用户要求添加）。
条目去向由桌面端沉淀时按内容判定，随身端不指定归属。

## 示例

用户口述：“刚才想到一个点子，可以用知识库的收件箱审阅机制做个每周回顾，把
一周内沉淀的知识串起来，应该能减少知识孤岛。”

```markdown
---
type: capture
capture_kind: 灵感
created: 2026-08-10T14:30
tags: [灵感, 知识管理]
---

# 每周回顾：用收件箱审阅串起沉淀知识

刚才想到一个点子：用知识库的收件箱审阅机制做每周回顾，把一周内沉淀的知识
串起来，应该能减少知识孤岛、让知识点之间产生连接。
```

## 摘录示例

用户口述："摘一句：天行健，君子以自强不息，周易里的。"

```markdown
---
type: capture
capture_kind: 摘录
created: 2026-08-10T16:00
tags: [摘录]
---

# 天行健，君子以自强不息

> 天行健，君子以自强不息。
> —— 《周易》
```
