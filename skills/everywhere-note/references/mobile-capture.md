# everywhere-note 随身端捕获（mobile-capture）

> 运行在手机/平板等移动或随身设备上时加载本文件。本部分**独立自洽**：手机端只
> 安装 everywhere-note 一个 skill 即可使用，不依赖知识库其他 skill。
>
> 条目字段是与 knowops desktop-ingest 共享的解析契约（`type`/`capture_kind`/
> `created`/`tags`/文件名）；修改字段时须同步更新 knowops 侧解析契约。
> GitHub 暂存库目录约定（`<知识库目录>/` 根目录放待入库条目、`归档/` 子目录放
> 已入库源文件）同样两端同步。

## 触发方式

用户调用（@/选中）本 skill 后**直接口述内容**即可，例如“记一下：XX”；不需要
用户说明“入库”“备忘”“晚上处理”等词。记录类请求一律走本流程。

## 核心流程（4 步）

### 第 1 步：判断 capture_kind（三分类）

| 类型 | 典型内容 |
|---|---|
| `灵感` | 顿悟、创意、新想法、想展开的思路 |
| `随手记` | 无明确类型的快速记录、备忘 |
| `待整理内容` | URL 素材、草稿、未完成材料、暂时说不清的内容 |

- 内容明显属于“待办 / 问题 / 日程 / 知识”时，**照实记录并在 tags 或正文标注**，
  但类型仍保持 capture——正式归类是电脑端审阅时的事，手机端不越权分类。
- 拿不准类型时默认 `随手记`。

### 第 2 步：生成暂存条目

按 `assets/capture-template.md` 模板生成**一条独立、完整、可复制的 markdown**：

- 标题：`# YYYY-MM-DD 一句话标题`（标题直接写在文本开头，电脑端会用做文件名）；
- frontmatter：`type: capture` + `capture_kind` + `created`（ISO 8601，精确到分钟）
  + `tags`（**行内数组** `[a, b]`，避免传输中被换行破坏）；
- 正文：保留用户原话，信息以用户给出为准，**不添油加醋**；语音转文字明显错字
  可顺手修正，但不脑补缺失信息；
- 末尾可附一行 `> 建议归属：<模块>`（可选，供电脑端审阅参考）。

### 第 3 步：输出

1. 先把完整 markdown 文本块展示给用户核对；
2. 若 agent **支持生成文件**：生成 `YYYY-MM-DD 标题.md`，保存到当前可用且用户
   可访问的位置（设备文件 / 备忘录 / agent 工作区等），保存后告知用户路径，
   并仍展示完整文本；
3. 若不支持生成文件：输出纯文本块供用户自行复制/保存。

**传输通道**：默认不做任何传输通道动作（不自动发送微信、邮件、云盘等）；唯一
例外是用户明确指定并确认的 GitHub 暂存库同步（见「GitHub 暂存库同步」）。未配置
同步时，内容如何到电脑由用户自行处理。

### 第 3.5 步：GitHub 暂存库同步（可选）

- **能力判断**：agent 自行判断平台是否具备 GitHub 能力（gh CLI / git / GitHub MCP
  等，任一可用即可）；不具备 → 跳过本步，维持本地输出。
- **配置来源**：暂存库配置（仓库 owner/repo、分支、目标知识库目录名）只存于
  对话上下文，同一对话内复用；**新对话重新询问**；用户可拒绝 → 跳过上传。
- **上传**：把本条目写入暂存库 `<目标知识库目录>/YYYY-MM-DD 标题.md`（文件名与
  本地条目一致）；本地是否另存文件不影响上传。
- **如实反馈**：上传成功 → 明确告知仓库与路径；失败 → 如实说明原因并保留本地
  条目，不假装已同步。
- **只上传本次条目**：仅上传本步生成的条目文件，不读取、不上传设备上其他内容，
  不泄露任何凭据。

### 第 4 步：设置入库提醒（默认 22:00）

- **规则**：仅当天确实产生了暂存条目时才设置提醒；当天没有记录不设置。
- **时间**：默认当晚 **22:00**，用户可指定其他时间。
- **合并**：同一天内多次记录只设一次提醒，提醒内容合并当天所有条目
  （例如列出“灵感：标题1 / 随手记：标题2”）。
- **已过 22:00**：记录时已过当天 22:00，提醒顺延至**次日 22:00** 并明确告知用户。
- **能力检查**：仅当平台确实支持提醒能力（系统提醒 / 日历 / IM / 定时任务等）
  时设置；**无法设置时如实告知**：“请记得 22:00 前把暂存内容发到电脑”，
  绝不假装已设置。

提醒内容模板（未同步）：

```
【知识库入库提醒】今天随身端暂存了 N 条内容：
- 灵感：标题 1
- 随手记：标题 2

回到电脑后，请把暂存内容发到电脑端 agent 并说“入库今天手机记的”。
```

已同步 GitHub 暂存库的条目，提醒结尾改为：

```
以上条目已同步 GitHub 暂存库。回到电脑后，说“入库”即可自动收入知识库。
```

## 补充格式要求

- 字段定义见第 2 步与 `assets/capture-template.md`；
- 文件名 / 首行标题：`YYYY-MM-DD 一句话标题.md`，日期前缀必须带；
- 可选字段：`source_url`（来自网页时）、`due`（明确截止时间时）；
- 标题要能让人 3 秒看懂内容；
- 电脑端将按 `capture_kind` 把条目放入 `00 收件箱/随手记|灵感|待整理内容/`。

## 红线

执行红线以 SKILL.md 为准。
