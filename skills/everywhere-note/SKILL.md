# everywhere-note 随身记录

## 定位

本 skill 用于手机/平板等移动或随身设备：用户调用（@/选中）本 skill 后直接口述
内容，生成符合知识库格式的 markdown 条目，并设置当晚 22:00 提醒。本 skill 独立
自洽，不依赖其他 skill；可选地，在用户指定暂存库且平台具备 GitHub 能力时，把
条目上传到 GitHub 暂存库，供电脑端自动入库。

## 路由

1. 移动/随身设备收到记录请求 → 加载 `references/mobile-capture.md`，按其中流程
   执行（判断 capture_kind → 生成暂存条目 → 输出 → GitHub 暂存库同步（可选）→
   设置提醒）。

## 红线

1. **信息以用户给出为准**：内容、时间、归属不自行臆造；缺关键信息时问一句。
2. **不越权分类**：只标 `capture_kind` 与建议归属，不决定内容最终进入哪个知识模块。
3. **不改动已有内容**：本 skill 不修改/删除知识库已有笔记。
4. **提醒不撒谎**：设置成功才说已设置；平台做不到时如实说明并给出手动替代。
5. **同步目标以用户指定为准**：只有用户明确指定了 GitHub 暂存库（仓库/分支/目标
   知识库目录）才上传；不猜测、不默认任何仓库。
6. **同步不撒谎**：上传成功/失败均如实告知；失败保留本地条目，不假装已同步；
   只上传本次生成的条目文件，不读取或上传其他内容与凭据。
