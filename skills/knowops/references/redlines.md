# 执行层红线与直写例外（knowops references）

> 执行任何 Obsidian 操作前先读本文件。通用红线（变更分级、回读校验等）见 SKILL.md；
> 本文件只规定执行层细节：删除纪律、git、配置引导、环境就绪、工具纪律、直写例外、
> 插件规则、安全边界。

## 删除纪律

- 只用工具的删除接口，**默认进系统回收站（可恢复）**；
- 严禁使用永久删除参数；严禁 `rm` / `Remove-Item` / `os.remove` 等绕过工具接口
  的删除方式；
- 告知用户"进回收站、可恢复"（流程内自动删除在执行后反馈中说明）。

## git

- vault 是 Git 仓库时，是否提交按用户手册「agent 约束」章执行；
- **补记用途**：整理/运营时发现无日记记录的用户改动，可用 `git diff` / `git log`
  辅助推断改动内容并补记日记（注明推断依据）；推断不了的不臆造，问用户；
- 「不代为 `git init`」红线不变。

## 配置引导（每次操作前）

- 先确定目标 vault → 读取 `.config/knowops.config.json`（`preferences.modules`
  模块索引/日记与模板目录/导出偏好）与 `03 系统/用户手册.md` 的「模块规则」
  「agent 约束」两章（**规则的唯一事实来源**）；
- vault 名、目录名、文件位置一律以配置与用户确认为准；配置缺失时询问用户，不猜测；
- 模块归属与分类**以手册为准、以库中实际存在且已登记的文件夹为准**；发现未
  登记的目录或漂移时按 `references/workflow.md`「模块发现与登记」问询，不静默
  写入未知目录；
- 找不到配置说明该 vault 尚未初始化，按 `references/init-config.md` 走初始化向导。

## 环境就绪

- Obsidian CLI 不可用或 Obsidian 未运行时，先拉起 Obsidian 再操作；拉起失败则
  提示用户手动打开，不静默继续。

## 工具纪律（官方 skill 优先）

- 任何 Obsidian CLI 命令或语法操作（读写改删、移动、日记、插件、Bases/Canvas/
  Markdown）执行前，先核对前置第 1 步记录的官方工具 skill 可用性；
- 对应 skill 已安装：**必须**加载该 skill 并以其指引为准执行；官方 skill 自身
  指导用 `--help` 查看具体命令语法时，属于遵循其指引，照做即可；
- 禁止的是**绕过官方 skill 自行探索**：未加载 skill 就凭记忆猜测参数、以
  `--help` 试探代替加载 skill、以网络搜索结果替代官方指引；
- 对应 skill 未安装或不确定：先告知用户并确认兜底方式——安装官方 skill，或按
  官方文档 help.obsidian.md 执行；用户确认前不开始操作；
- **安装指引**：官方工具 skill 来自 kepano/obsidian-skills
  （https://github.com/kepano/obsidian-skills）——把仓库中对应 skill 目录复制
  到 agent 的用户级 skill 目录即完成安装（与 knowops 本身的安装方式相同）；
  用户确认安装后按此执行，装不上再回退官方文档兜底；
- 例外：用户明确同意自行探索（如「直接试试」）时按用户指示执行，但命令失败
  即回报请用户决策，不反复重试轰炸。

## 直接文件访问例外清单

默认一律走工具接口；以下场景可直读直写文件，且**必须在回复中说明原因**：

| # | 场景 | 说明 |
|---|---|---|
| 1 | 工具不可用 | 工具未安装/应用未运行，且用户明确同意继续 |
| 2 | 格式校验 | 需对原始文件做 JSON / YAML / Canvas 结构校验 |
| 3 | 二进制附件导入 | 工具不支持二进制内容时直接复制文件 |
| 4 | 批量读取源文件 | 如 HTML 镜像导出：不依赖应用运行，需批量读源 |
| 5 | 超长内容 | 命令行参数可能被截断：工具先建占位文件，再直写完整内容 |
| 6 | 隐藏目录内文件 | 点开头目录（如 `.config/`）工具接口无法访问，可直写 |

## 插件规则

- 插件集成规则存于用户手册「agent 约束」章，操作后按其执行（如版本提交、同步）；
- 插件安装/卸载/规则变化先经用户确认，并更新该章。

## 安全边界

- 知识库无关文件（配置/变更记录/脚本副本/导出产物）写入隐藏目录
  `.config/`，不写入用户笔记内容区（操作记录＝日记在 `03 系统/日记/`，待审阅
  文件在 `00 收件箱/`，agent 约束在用户手册「agent 约束」章，均属可见内容）；
- **用户手册是规则正文**：用户可见可编辑，同时是 agent 必读的规则来源；agent
  修改手册仅限模块登记/注销、经用户确认的规则变更与用户明确要求，不做其他
  改写；config `preferences.modules` 是机器索引，与手册由同一次登记流程写入，
  不单独漂移；
- **待审阅文件保护**：`待审阅-YYYY-MM-DD.md` 是 agent 写入审计的运营件——
  沉淀流程跳过、不参与相似检查与序号计算、不参与 HTML 导出；用户审阅前不
  代删，用户明确说删除时走删除接口（进回收站）并记日记；
- 用户自建的白板（`.canvas`）等非笔记文件是用户自由空间：不主动整理、不校验、
  不导出、不报错；用户要求操作时按相应工具规范执行；
- 不对用户笔记做批量扫描式改写；修改前先看方案。
