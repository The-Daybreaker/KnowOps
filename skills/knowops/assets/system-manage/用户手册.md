# 知识库 · 用户手册

> 本手册在首次初始化时由 AI agent 自动生成，面向知识库使用者。
> 可以随手修改或删除；重复初始化不会覆盖本手册。

## 这个知识库怎么用？

你的知识库由 **Obsidian + AI agent** 共同维护：

- **你**：在 Obsidian 里自由写作、浏览、建立链接；
- **AI agent**：在对话里帮你捕获、整理、搜索、写日记、做视图、导出网页版。

对 agent 说出需求即可，例如：

| 你说 | agent 做 |
|---|---|
| "记一个灵感：……" | 写入 `00 收件箱/灵感/`（带日期前缀） |
| "帮我记录一个问题：……" | 归入 `01 生活系统/问题/未解决/`，联动任务与日志 |
| "摘录：君不见黄河之水天上来……" | 长篇作品建独立笔记到 `06 摘录系统/长篇/`；短句追加到 `06 摘录系统/短篇/` 对应分类文件 |
| "周五下午 3 点项目评审" | 创建 `01 生活系统/日程/` 笔记，含时间属性 |
| "审阅收件箱" | 逐条判断价值：沉淀到对应模块 / 删除 / 归档 |
| "这个问题我搞懂了" | 移入 已解决，记录解决日期，勾选任务 |
| "沉淀这个问题" | 判定知识类型经你确认后建知识笔记并双向链接，原问题移入 已沉淀 |
| "建一个项目：xxx" | 在 `05 项目系统/进行中/xxx/` 建项目六文件 |
| "我有哪些待办？" | 汇总任务笔记与 TODO.md |
| "打开看板" | 打开 `07 看板/看板.md`（Bases 实时聚合） |
| "把这篇笔记归档" | 移入 `08 归档/<归档当日日期>/` |
| "入库今天手机记的" | 优先收你提供的内容；配置了 GitHub 暂存库时自动拉取新条目写入 `00 收件箱`，源文件归档至暂存库 |

## 内容一定分门别类

简短、零碎、临时内容默认进 `00 收件箱`；明确的问题、日程、项目直接进对应
模块；摘抄的诗词、名言警句等进 `06 摘录系统`。收件箱会定期审阅：有价值→沉淀
成正式笔记，无价值→删除（回收站），过时→归档。

## 常见问题（FAQ）

**Q：agent 删错了怎么办？**
A：删除永远进系统回收站，打开回收站还原即可。

**Q：我在 TODO.md 里勾选任务有效吗？**
A：有效。任务笔记与 TODO.md 互为镜像、双向同步；你直接勾选/新增会被识别并
同步到任务笔记，冲突时 agent 会先问你。

**Q：知识库的规则在哪看/改？**
A：`09 系统管理/` 下：知识库架构、分类规则、记录规范、变更记录，
以及本手册，都是可见笔记，可直接编辑。

**Q：08 归档 / 其他模块目录平时看不到？**
A：正常。模块目录是懒加载的，Obsidian 不显示空文件夹；首次归档/写入时目录会
自动出现（如首次归档时生成 `08 归档/2026年08月09日/`）。

**Q：手机记的内容怎么进电脑知识库？**
A：手机端（everywhere-note）生成条目后，若指定了 GitHub 暂存库且平台具备 GitHub
能力，会自动上传到暂存库中本知识库的目录；回到电脑说「入库」，agent 会从暂存库
拉取新条目写入 `00 收件箱`，并把源文件归档到暂存库 `<知识库名>/归档/<入库日期>/`
（本地不重复存放）。暂存库在电脑端初始化时配置。

**Q：插件（如 git/同步）怎么生效？**
A：初始化时与你确认后由 agent 自动执行（如先版本提交、再同步）；规则调整可随时提出。
