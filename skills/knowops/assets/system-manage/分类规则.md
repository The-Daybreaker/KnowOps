# 分类规则（本库定制）

> 本文件记录当前知识库的分类约定，是默认「分类原则」的落地实例，供你了解
> 内容如何归类。

## 核心问题

分类时不问"它属于哪个目录？"，而问"未来我会怎么使用它？"

1. 用于解释（是什么/为什么）→ 02 知识系统/概念原理
2. 用于指导行动（应该怎么做/遵守什么）→ 04 规范系统 或 02 知识系统/经验方法
3. 用于复制（可复用的骨架/流程）→ 03 资产系统/模板 或 工作流
4. 用于解决类似问题（怎么解决一类问题）→ 02 知识系统/方案
5. 只是参考（真实发生过的事例）→ 02 知识系统/案例
6. 用于收藏（回顾、引用、欣赏的摘抄句子或作品）→ 06 摘录系统

## 路由表（默认，可覆盖）

| 内容特征 | 目标位置 |
|---|---|
| 简短/零碎/临时的顿悟、灵感、想法、不明确内容 | 00 收件箱（随手记/灵感/待整理内容） |
| 明确完整的问题 | 01 生活系统/问题/未解决 |
| 明确完整的日程 | 01 生活系统/日程 |
| 明确的可执行任务 | 01 生活系统/任务 |
| 解释类知识 | 02 知识系统/概念原理 |
| 经验做法 | 02 知识系统/经验方法 |
| 解决方案 | 02 知识系统/方案 |
| 参考事例 | 02 知识系统/案例 |
| 应遵守的要求 | 04 规范系统（原则/标准规范/检查清单） |
| 可复制的骨架/流程 | 03 资产系统（模板/工作流） |
| 要创造的东西 | 05 项目系统/进行中 |
| 诗词、文言等长篇作品摘抄 | 06 摘录系统/长篇（诗词/文言/文学/网络） |
| 名言、警句等短句摘抄与个人单句感悟 | 06 摘录系统/短篇（名言/警句/思考/摘抄） |
| 过时/不再活跃但需保留 | 08 归档 |

## 无法判定时

- 默认先进入 00 收件箱/待整理内容；
- 审阅时仍无法判定的，询问用户归属；
- 不自创模块、不静默放置；新增模块/知识类型先向用户确认。

## 新增模块条件（三者需同时满足）

1. 内容规模足够（少量内容保持在现有模块内）；
2. 有独立生命周期（开始 → 过程 → 结束 → 复盘）；
3. 有独立工作流（输入方式、处理流程、输出结果）。
